═══════════════════════════════════════════════════════════════════════════
                            DATA FLOW
═══════════════════════════════════════════════════════════════════════════

INGESTION:
  PDF → Extract Text → Chunk → Embed → Store in ChromaDB

QUERY:
  User Query → Classify Intent → Retrieve Context → Route
                                                      ├─→ AI Response
                                                      └─→ Human Escalation

✓ Intent Classification
✓ Conditional Routing
✓ Human-in-the-Loop (HITL) Escalation

═══════════════════════════════════════════════════════════════════════════
                         ROUTING LOGIC
═══════════════════════════════════════════════════════════════════════════

ESCALATE TO HUMAN IF:
  • Retrieval confidence < 0.7
  • Intent = "complaint" or "technical_issue"
  • Intent confidence < 0.6
  • User requests human

OTHERWISE:
  • AI generates response
